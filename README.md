# Dart Learning Lab

Projeto criado para estudo e prática dos fundamentos da linguagem **Dart**.

## Conteúdos praticados

- Variáveis e tipos de dados
- Inferência de tipos
- `final` e `const`
- String interpolation
- Null Safety
- Funções
- Parâmetros nomeados e opcionais
- Classes e objetos
- Construtores
- Encapsulamento
- Getters e setters
- Herança
- Abstração
- Polimorfismo
- Sobrescrita de métodos
- `List`
- `Set`
- `Map`
- `where()`
- `map()`
- Estruturas de dados aninhadas
- Tratamento de exceções
- `try`, `catch`, `on` e `throw`
- Exceções personalizadas

## Objetivo

Praticar os principais conceitos da linguagem Dart e criar uma base para futuros estudos com Flutter.

## Tecnologias

- Dart
- Android Studio
- Git
- GitHub
